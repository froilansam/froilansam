### 🧠 How I work

- 🎨 **UI first, but not UI only.** I lean toward front-end and UI architecture, and I'm comfortable going down to the database when the bug lives there (it usually does).
- 🚀 **Product brain on.** I build features that solve real problems and move the product forward, not features that only look good in a demo.
- 🤖 **AI where it helps.** Image and voice input, smarter forms, automations. The AI does the boring part and the user stays in control.
- 🧪 **Typed, tested, documented.** Future me is a real person and deserves nice things.
- ♿ **Responsive and accessible by default.** If a thumb can't hit it, it isn't a button yet.
- 📚 **Always learning.** New tool, new language, new system? I'll read the docs. Eventually. After trying it first.
