## How I work

| | |
|---|---|
| **UI first, not UI only** | I lean toward front-end and UI architecture, and I'll go down to the database when the bug lives there (it usually does). |
| **Product brain on** | I build features that solve real problems and move the product forward, not ones that only look good in a demo. |
| **AI where it helps** | Image and voice input, smarter forms, automations. The AI does the boring part, and the user stays in control. |
